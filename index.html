( 03 )HOW I SOLVE PROBLEMS

From a vague question
to a clear next move.

A good dashboard is not just a collection of charts. It is a decision tool: built around the question, the people using it, and the action the data should unlock.

MY ANALYST LOOP ↘
01
Frame the question

Clarify the goal, audience, constraints, and the decision hiding behind the request.

↗
02
Clean the signal

Inspect missing values, duplicates, formats, outliers, and the shape of the data before trusting it.

↗
03
Find the pattern

Use Python, SQL, and exploratory analysis to compare segments, trends, and performance drivers.

↗
04
Build the view

Turn the important signals into an interactive dashboard with hierarchy, KPIs, filters, and context.

↗
05
Recommend the move

Finish with the “so what?” — a concise insight, opportunity, risk, or action someone can use.
